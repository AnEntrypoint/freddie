# AGENTS.md — ui-skill

## Rationale

- `src/client/index.js` `notifyLexicon`: listener failures are caught and logged. Settlement notifies from an ignored promise chain (a throw would surface as an unhandled rejection), and one faulty consumer must not starve the others.
- `src/client/index.js` `source.candidates`: the user-only marker rides the candidate `description` (the menu's only secondary text). `hint` is the claim-state ghost text (`ui-conversation` `input/decorations.js`), not a badge.
- `src/client/index.js` `source.onPick`: the pick lands as plain text `/name ` and the prompt ships the same literal. Determinism is host-side: the `freddie-tool-skill` `agent/pre-step` boundary recognizes the leading `/name` and injects the rendered body for every entry point. A name shared with a host command still resolves to the command, because adjudication claims the line client-side before it becomes a prompt.
- `src/client/index.js` `agent-preset/selected` invalidation: a preset decides which skill providers an agent reads, so a switched session's cached catalog belongs to a composition it no longer runs.
- `src/client/index.js` catalog cache: fetches are cached per session (small twin of the ui-commands directory), so per-keystroke candidate polls filter a settled snapshot locally and a session costs one RPC. The scope-birth warm hook prewarms the session key; connection/reset clears everything because the host catalog may differ across generations. A shared in-flight fetch outlives any single menu interaction (closing the menu must not kill the prewarm other consumers hit), so it carries its own abort, fired only on invalidation/teardown; a candidates caller with an aborted signal just returns early.
- `src/client/index.js` RPC: `skill.list` is addressed by the per-call session projection's sessionId (sessions are always agent-backed; the host resolves cwd from the session header) and rides the plugin's root-context connection captured at registration. `disable-model-invocation` skills are absent from the model-side catalog but still injected by the pre-step boundary (issue #1470). Draft chip visuals derive from the lexicon scan; the source implements no reference codec.
- `src/client/SkillRow.js` `resultText`: keep aligned with ui-tool `models/tool-call-model.ts` `resultText` (generic Tool-row text contract).
- `src/invariant.js`: no runtime invariant. Slash source, dictionaries and keyed toolview are registry-owned registrations disposed by the registry; they emit no cordis events and own no cross-plugin mutable state.
