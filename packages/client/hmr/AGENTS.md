## Rationale

- The shared `__FREDDIE_HMR__.events` array survives driver replacement and shell remount. Async work from an old driver appends in place and writes tree verdicts to `liveStatus()`; it must not overwrite the new driver's journal or connection status.
- `wireGraph` receives the authoritative connect graph and patches rebuilt rows. `remountShell` writes it to `__FREDDIE_BOOT__` before constructing a new entry, preventing stale revisions.
- All swaps and terminal recovery use one queue: concurrent dispose/execute chains would corrupt the Loader handoff. Unknown frame types fall through because the frame union is merge-extensible.
- Client reload order is invalidate → prefetch → registry deletion → drain old fiber → clear `entry.fiber` → remove owned styles → refresh → await startup. Invalidate precedes prefetch or a live record makes prefetch a no-op. Registry deletion precedes disposal or Loader permanently disables the entry; a retained fiber makes refresh a no-op. Provider epochs cascade dependents.
- Reload failure or graph mismatch remounts the shell; a sequence gap reloads the document. There is no rollback. Prefetch failure leaves the old fiber running; a later rebuilt frame retries. A rebuild overlapping boot can briefly materialize old bytes; the next frame heals it.
- `verifyTree` consults shell health after reload/remount because non-throwing boot entries can still conceal failed mounts, pending entries, or an empty root. It attempts one remount, then presents failure with one automatic reload. It uses `console.error`: remount replaces the Context owning the old logger exporter.
- `AUTO_RELOAD_KEY` is spent in sessionStorage before reloading and refunded only after health passes. Unreadable storage counts as spent, preventing a reload loop.
- `watchRow` rehashes after its baseline: a write between the module host's graph hash and that baseline must not become silently current. Self-watching includes HMR's own row; graph changes update watcher membership.
- Native watch is non-recursive per directory and re-arms on rename/error; Linux recursive watch can lose an atomically replaced path. Polling covers incompletely watched roots. Checkout-only static roots are omitted from packaged deployments.
- Without `cssManifest`, stylesheet changes publish `shell-rebuilt` for root `styles`; there is no manifest link to swap. Frame kinds and public configuration live in [README.md](README.md).
- The fiber-local handle ledger survives module replacement via Symbol.for. Watcher close events remove watchers; timer disposers remove intervals. The invariant awaits disposer scheduling, fiber quiescence, and one setImmediate for watcher close events. Process-wide handle counts include unrelated plugins; StatWatcher counts cannot observe fs.watch. Its async internal/plugin listener deliberately returns rejections for the framework reporter.
- Only WebSocket upgrades join `/plugins/events`; ordinary HTTP requests return 426. Origin matches Host using the Origin scheme, supporting TLS proxies without trusting forwarded headers. Cross-site upgrades are refused; originless native clients remain supported.
- Six persistent HTTP/1.1 HMR streams can exhaust the browser request pool. WebSockets avoid that budget, disable compression, and bound pending bytes plus the complete next frame. Client generations own their retry and liveness timers; disposal and terminal recovery prevent late reconnects ([decision](../../../.agents/notes/implemented/architecture/2026-10-06-hmr-websocket-connection-budget.md)).
