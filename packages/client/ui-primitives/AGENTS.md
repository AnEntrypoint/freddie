# client-ui-primitives

## Rationale

- `markdown/CodeBlock.js` and `ReadBlock.js` `ensureHighlightModule`: `markdown/highlight.js` (shiki core, grammars) stays a dynamic `import()`; a static import put dozens of unbundled dev-mode ESM files on the boot critical path. Cards render plain until it resolves.
- `CodeBlock.js` / `ReadBlock.js` `#render`: highlight output is memoized on (code, lang) because renders repeat per stream chunk or copy tick and tokenizing is a full grammar scan. An `undefined` result (module or grammar still loading) is never memoized, or the load-completion re-render stays plain forever. `ReadBlock` highlights its whole window in one call to keep grammar context across lines.
- `CodeBlock.js` `#render`: `innerHTML` is safe only because the HTML is shiki's own span tree built from `code`; never feed it any other string.
- `markdown/highlight.js` `scheduleWarmup`: the engine and grammar build is a 120-175ms long task, so it runs on `requestIdleCallback` (an `unref`'d `setTimeout(0)` in Node); `ensureGrammar` is the correctness fallback for a fence rendered earlier.
- `markdown/incremental.js` `update`: the `text.startsWith(this.prevText)` check is a deliberate O(prefix) compare, the only sound divergence test without pushing append/reset deltas across the session-projection boundary.
- `markdown/JsonBlock.js`: `bodyText` needs `?? String(payload)` because `JSON.stringify` can return `undefined`.
- `markdown/MarkdownText.js` `#render`: skipping on equal props AND `#painted` is required, not an optimization: webjsx re-walks cached real DOM children each pass (40 fresh inline `code` elements per keystroke observed). `disconnectedCallback` clears `#painted` because children may move while detached.
- `markdown/render.js` `renderCode`: `CodeBlock` is a stateful custom element that applyDiff's VNode shape cannot carry, so a raw `<freddie-code-block>` host stands in the tree and its `ref` hands props to the reused instance. `code` is `${node.value}\n` because CodeBlock's display trim removes one trailing newline; the language id is `/^[\w-]+/`; `math` fences settle as display TeX.
- `renderTable` / `renderTableRow`: `md-table-wide` (>= `WIDE_TABLE_MIN_COLUMNS`, not in a blockquote) is the hook `AssistantMarkdown.css` widens past the message column; it gets `tabindex=0` because `overflow-x: hidden` drops Chromium's implicit scroller focusability. With alignment every row renders exactly `align.length` cells; alignment is a `style="text-align: ..."` string because webjsx has no style-object prop.
- `markdown/render.js` DOM parity with the replaced hast pipeline: `<br>` is followed by a `
` text node, inline-code line endings become spaces, and list-item `
` placement follows tight/loose rules; keep these when touching `renderNode`.
- `inlineCodeHttpUrl`: the case-insensitive `HTTP_URL_PREFIX` gate runs before `new URL()` (a throwing parse is far costlier, and this runs per inline code span per render); the value is authored text, so it skips `normalizeUri`. File-mention buttons are suppressed inside an anchor (`inLink`; a button cannot nest in `<a>`); an unresolved link reference reverts to its bracketed source without setting `inLink`.
- `DiffBlock.js` `#render`: head/tail split (`ceil(maxLines / 2)` head) must match `TerminalBlock` and the TUI transcript's collapsed card so slices agree across front ends. A path header opens each new
file and a same-file second hunk opens with a `⋯` gap; the footer counts DISTINCT paths (TUI
parity). Side text splits like TerminalBlock output: empty is zero lines, one trailing newline is
a terminator. `freddie-llm` is not a dependency, so the exhaustiveness helper is local.
- `ansi.js` `replayLine`: erase-in-line `K` is needed or a shorter redraw leaves the previous frame's tail; `1K` blanks line start through the cursor column inclusive (cells blanked, cursor unmoved) and only the first `;` parameter selects the mode. A wide char is a lead cell plus a `spacer`; overwriting either half blanks the other, and an orphaned spacer still emits one space or later columns shift left. `ZERO_WIDTH` marks attach to the previous cell and are dropped with none.
- `ansi.js` `WIDE_SCRIPT_RANGES` (used by `WIDE_CHAR`): the double-width ranges are a numeric code point table, not `\p{Script=...}` properties, so the character set is pinned and reviewable in source; it was generated from the Unicode script data and checked equal to the property form over every code point.
- `ansi.js` closing convergence: the emitted state must converge to the state the scan ENDED in, not the last written cell's; a trailing `\x1b[0m` changes no cell but ends the run, else a color leaks into the DOM and the next line.
- `ansi.js` `applyCursorMovements`: lines with no `\r`/`\b`/erase skip the column buffer (a cell per character of `ls -R` or a 5k-line log) and only fold their SGR. `resolveStyle`: a run with its own background keeps anser's literal rgb pair so authored contrast survives; a foreground-only run maps to a theme token for light and dark.
- `WebBlock.js` `renderAnswer`: `markdownText` is the caller's caching renderer (`ui-tool` `cachedBlock(..., 'web-answer', ...)`, `#webAnswerEl`); `MarkdownText`'s one-shot factory recreates its element per call and drops settled-render memoization. An empty retrieval renders `No results found.` (mirrors `tool-web/src/search.js`). The card draws every source the view carries because `freddie-spill-policy` shrinks only `content`, never `meta`.
- `Modal.js` / `OnboardingSurface.js`: the overlay is appended to `document.body` so ancestor stacking contexts cannot leave page controls above the mask; it stays an in-page dialog. `OnboardingSurface` `#root` is `inert` exactly from `connectedCallback` to `disconnectedCallback`; a step rendering null mounts and blocks nothing.
- `Modal.js`: `disconnectedCallback` calls `#syncFocus(false)` because `.remove()` on an open modal never reaches the `!open` branch that restores focus. `#trapTab` wraps Tab (`aria-modal` promises a trap) over a live-queried focusable set, falling back to the dialog container when all actions are disabled. `#syncFocus` is a one-shot open/close transition guarded by `#wasOpen`, never a per-render effect.
- `modal-stack.js` `isTopmostModal`: every open `Modal` keeps its own document `keydown` listener, so with two dialogs stacked an unguarded Escape closed both and each Tab trap pulled focus to its own dialog from behind the other. Only the last `[role="dialog"][aria-modal="true"]` in document order acts; that is the rule the shortcuts keyboard adapter uses to name the active modal, and `SettingsRoot` shares this helper instead of a private copy. Document order, not creation order, decides, so a persistent element that reopens keeps its original place in the stack.
- `Toast.js`: the `hint` span is reserved width so the message text is never swapped; a refused clipboard write shows no false "Copied". Hover or focus cancels the 4s auto-dismiss (`HOLD_MS + FADE_MS`) and its CSS fade; leave restarts a full cycle, not the remainder.
- `Tooltip.js` `#render`: the fit handler runs after `applyDiff`; the first `fit()` inside `#bindFit` runs before the bubble exists and is a no-op. The bubble is `position: fixed` to escape ancestor clipping without a portal.
- `Menu.js`: `portal` appends the list to `document.body` for anchors in overflow-clipping containers; lists scroll (`.scrollable`) except menus with submenu rows, whose side card an overflow clip would crop. `#moveFocus` queries `[role="menuitem"]:not(:disabled)` live (portal list when present) instead of tracking an index.
- `Menu.js` (`#armGrace`) and `HoverCard.js` (`#armClose`) each carry their own inline 200ms pointer-grace close timer; keep the two in step. The portaled list and card are appended to `document.body`, so they are not descendants of the wrapper that arms the timer. Each surface binds its own enter (cancel) and leave (arm) pair. A wrapper-only handler closes the popup while the pointer is still crossing the gap to it.
- `define-element.js`: `customElements.define` binds a tag for the document's lifetime, so a hot-reloaded class registers as `tag--v2`, `--v3`... and an alias map (on `globalThis` under a `Symbol.for` key, so a shell remount under a new URL prefix shares it and installs the `createElement` patch once) points the logical tag at the newest. The first definition uses the bare tag.
- `markdown/highlight.js`: boot grammars are TypeScript, shell, JSON; js/jsx/ts/tsx alias to the TypeScript grammar (JSX tokenizes approximately). Read-card extension grammars (`LAZY_GRAMMARS`) load on first use, render plain meanwhile, and notify `subscribeGrammarLoaded`. The alias table is a `Map` so assistant-authored fence labels like `constructor` or `__proto__` miss. Grammar patterns compile eagerly (warmup) so the 500ms per-line shiki budget is spent on user content only. Colors are `--shiki-*` tokens in the theme package, never here.
- `markdown/incremental.js`: the last `UNSTABLE_TAIL_BLOCKS` blocks stay unfrozen; the cut is the end offset of the last frozen block (keeps inter-block blank lines in the tail). Known deviation: a reference link or footnote whose definition is across the freeze boundary renders literally until the settled full parse heals it. Streaming grammar has no math, so `$$` is a paragraph while streaming and a math block once settled.
- `markdown/render.js` policy: link and image destinations pass a protocol allowlist, images also need absolute HTTP(S), raw HTML renders as literal text, KaTeX runs without trusted commands, fragment-anchor URLs fail the allowlist so footnote refs render as plain text. Unknown node types render nothing instead of `assertNever` because grammars registered elsewhere may add types.
- `markdown/katex.js`: KaTeX HTML is parsed with `DOMParser` and mapped to VNodes; MathML lands by tag name only (assistive tech reads it regardless of namespace).
- `WebBlock.js` `safeHref`: only http(s) becomes an anchor (MarkdownText also allows `mailto:`, excluded because a retrieval URL is never a mail address).
- `Toast.js`: `HOLD_MS` and `FADE_MS` must equal the stylesheet's toast-fade delay and duration or the banner unmounts mid-fade.
- `ansi.js`: `SgrState` holds current fg/bg/attrs, not sequence history (accumulating chains was O(n^2): 3200 cells produced 25 MB and a `RangeError`) and lets `39`/`49`/`22`... closers actually close. Basic 8/16 colors map to theme tokens (black and white both to primary label, bright black to tertiary); magenta, cyan, 256-palette and truecolor keep anser's literal rgb. Blink is not reproduced. `\r` and `\b` only move the cursor (`100%\rOK` shows `OK0%`), and CSI state changes what the NEXT writes are stamped with.
- `RiskConfirmation.js` holds one `freddie-modal` across renders via `renderModal(this.#modal, ...)`; the one-shot `Modal(...)` appends a new modal per call and orphaned stale modals that swallowed clicks.
- `useAnchoredPosition.js` re-measures on capture-phase scroll, resize and panel size change; `useAnchoredMaxHeight.js` clamps bottom-anchored overlays (they grow upward) to the space below the viewport top. Both are start/stop closures whose `.value` the owner reads after `onChange`.
- `icons/index.js`: glyph names are the figma `ic_ds_*` names; `agent_preset` masks node interiors to transparency; `folder_open` outline variant omits the 20%-opacity inner fill to match the `...Outline16` weight; `sparkle_16` is hand-authored (source is an SF Symbols text glyph); `archive_outline_20` drops the export's 0.11px duplicate contour.
