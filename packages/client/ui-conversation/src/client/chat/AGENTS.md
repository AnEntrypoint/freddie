# AGENTS.md — ui-conversation/src/client/chat

## CSS rationale

- `ChatView.css`: `.root` is an inline-size query container so wide markdown tables size their breakout against its content width (`100cqw` in `AssistantMarkdown.css`). `.flowItem:empty` is hidden because a keyed renderer may decline its row after dispatch (the completed-turn tail with neither actions nor extensions) and an empty flex item must not consume the column gap. The turn-activity pulse is opacity-only (compositor-only, cheap under reduced motion with no separate branch). `.toBottomSlot` is a zero-height sticky slot so the control does not extend `scrollHeight`; it sits above the sticky composer (z-index 8 over 7) and its bottom clearance follows `--freddie-composer-height`, published by `ConversationRoot.js` (the 152px fallback covers the first paint before the seat observer fires).
- `AssistantMarkdown.css` `.contents`: `display: contents` keyed wrapper standing in for the React Fragment webjsx lacks, so an image gallery still joins `.body`'s flex column. `.md-table-wide` (the renderer's 4+ column hook) breaks out to the full transcript width with `100cqw` of the ChatView container: `--freddie-table-spare` clamps to zero when the transcript is narrower than the message column (no sideways shift), the lead padding compensates the negative margin so table content starts at its normal x, and percentages resolve against the wrapper's containing block so a table inside a list reaches the same edges. The base `.tableScroll` caps at the column, which the breakout must exceed.
- `StatsLine.css`: `display: block`, not flex, since `text-overflow` only elides a block's inline content. `MessageIconActions.css`: the time label fades in on hover or keyboard focus within a `data-time-hover-root` scope (set by `MessageItem.js`, `TurnTailNodeView.js`) using opacity so layout stays stable; devices without hover keep it visible.
