## Rationale

- `src/index.js` constructor: `root` and `extraRoots` are resolved to absolute paths once so a later `process.cwd()` change cannot split one backend across roots; config defaults are re-applied with `??` because programmatic wrappers can construct the backend without schema normalization.
- `src/index.js` teardown effect removes `writerLockPath` so an ordinary restart does not reclaim its own stale lock; a crash skips it and `claimWriterLock()` reclaims via pid liveness. `processAlive` treats `EPERM` as alive (process exists under another user).
- `src/index.js` `readFrom`: JSONL is sequential media and defines no `loadStoredFrom` hook, so the coordinator parses the stored prefix and skips forward to `fromSeq`. Keep the service API next to its storage hooks; extracting the forwards would add an inheritance layer.
- `src/index.js` `readRaw`: each decoded frame is copied with `Buffer.from` because the private zstd decoder reuses its native output buffer across yielded frames. The logical filename is always `session.jsonl`; the `.zstd` suffix only marks physical compression.
- `src/index.js` `readPrefix`: a parse-time `SessionFormatUnsupportedError` predates any `SessionHeader`, so the coordinator's locate-based enrichment cannot run; the raw log location is attached here.
- `src/index.js` `readZstdPrefix`: a structurally incomplete final frame may end before the decoder emits any plaintext, so a failed `decompressZstdPrefix` keeps the complete prior frames (recovered events are then empty).
- `src/index.js` `listArtifactsAt`: one unreadable artifact is warned and skipped, never fatal, because listing runs during workspace init and a single damaged file otherwise leaves the harness unstartable with a diagnostic naming the plugin instead of the file.
- `src/index.js` `materializePosix`: publish uses `link()` then unlink, not `rename()`, so a concurrent materialization of the same id fails with `EEXIST` instead of silently overwriting. The directory is fsynced after `link()` because the entry is not crash-durable until then; the redundant temp link is removed best-effort and must never reject an already-published append.
- `src/index.js` `rejectExistingLog`: unreachable in practice because `createCore` guards collisions first; it is a TOCTOU backstop that refuses to publish over a committed log.
- `src/index.js` `exists`: only `ENOENT` means absent; other errors surface so load and collision checks never proceed under false absence. Windows reports `ENOENT` (not `ENOTDIR`) for `regular-file/child`, so `assertLogParentAllowsAbsence` checks the parent.
- `src/win32.js` durable-directory probe: a bare drive root is used as-is because Node rejects its extended-length spelling with `EISDIR`; descendants keep the namespaced form for long-path probes.
- `src/win32.js` `createLeafDirectoryWin32`: the `mkdtemp` staging name is independent of the target basename so a legal 255-byte component cannot make the sibling staging name too long.
- One append-only file per session under human-navigable project directories; session ids and project paths are encoded injectively (`~XXXX` escapes; the project key is intentionally lossy). A `.writer.lock` gives one process append rights per root (two writers would collide on seq numbers and the scanner refuses the whole session); stale pids are reclaimed. Foreign-home header listing does not claim the lock. Append restores the previous size on partial write or sync failure so retry cannot duplicate seqs. Repair truncates the torn tail, restores complete events decoded from it, then appends synthetic closers (two fsync'd steps, not atomic).
- Windows durable namespace (`win32.js`): Node cannot fsync a parent directory, so publication uses staging siblings plus `MoveFileExW(MOVEFILE_WRITE_THROUGH)` without replace or copy fallback; races are accepted only after verifying the winner is a directory. Koffi loads lazily.
- Zstandard: concatenated independently checksummed frames; a Node-private synchronous multi-frame decoder is used when the running Node 22/24/26 exposes the expected stream handle shape, else the public one-shot decoder. `ZSTD_e_flush` recovers plaintext from a torn final frame.
