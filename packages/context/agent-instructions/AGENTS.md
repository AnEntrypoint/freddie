# AGENTS.md — agent-instructions

## Rationale

- `src/render.js` `frameAsSystemReminder`: the plugin bakes the complete `<system-reminder>` frame into the message content. The session surface projects context verbatim and does not wrap it, so any framing lives in the producer's content (deferred note: `.agents/notes/implemented/simplification/2026-07-20-unwrap-injected-content-envelopes.md`).
- `src/files.js` `nodeStatFile`, `fsStatFile`, `probeScopeInstruction`: a final-component symlink is followed (`stat` / `fileSystem.resolve` then `stat`), so a link to a regular file loads. A missing path, broken link, or non-file target (including a link to a directory) is `absent`; only a provider exception is `unavailable`. In `allExistingInstructionFiles` an `unavailable` candidate skips only itself so the independent candidates still load.
- `src/state.js` `reconcileInstructionContext`: same-directory candidates form one deduplicated authority group. If an active member is `unavailable`, the whole last-good group is preserved, so cache warmth never decides whether a sibling transition is emitted. When rendering leaves no transition (tiny budgets render notice-only text) nothing is emitted or committed; the uncommitted versions make the next pass retry.
- `src/index.js` `projectionTails`, `openSteps`, `stepTouches`: emit listeners are not awaited, so each projection composes against the inbox produced by earlier file results for the same agent. Execution ancestry and the enclosing durable step are the two commit boundaries before an asynchronous projection may mutate the agent inbox.
- `src/index.js` `agent/pre-step` handler: an empty first entry (`step === 1`) owns a no-step turn, so context stays pending instead of becoming a standalone request. A proceeding step settles the pending context, which is folded right after the claimed batch (direct prompt before it, driver-appended runtime context after).
- Known gap `src/files.js` `existsAsMarker`: a provider failure is reported as absence, so root discovery continues upward and can cross into an ancestor project. Provider failure should stop discovery.
- Known gap `src/files.js` `readBounded`: the cap is per file; there is no aggregate source budget across a baseline or reconciliation batch. The render budget applies only after every accepted file has been read.
- Known gap `src/state.js` `reconcileInstructionContext` and `src/index.js` `compose`: the project root is recomputed on every pass instead of frozen per loop instance, so editing a root marker reinterprets the existing relative scope keys.
