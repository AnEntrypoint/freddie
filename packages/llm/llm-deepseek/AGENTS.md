# AGENTS.md — llm-deepseek

## Rationale

- `src/adapter.js` an uncatalogued endpoint is treated as text-only: declaring an unverified image capability would let the host persist input the endpoint may reject on every later turn.
- `src/adapter.js` stream call: connection facts and the credential resolve once per call from one snapshot, so an in-flight stream never sees a configuration change and an endpoint and the secret sent to it never come from different generations. A return-time abort adds no outcome (the consumer controller owns termination). The HTTP status stays authoritative when a gateway returns malformed JSON; acptoapi's `chain_exhausted` error `hint` (each fallback link's failure reason) is appended to the message because it is otherwise dropped.
- `src/adapter.js` open item: adopt the Cordis HTTP service when shared transport configuration outweighs its added runtime dependencies (currently plain `fetch`).
- `src/file-store.js`: once a mapping wins, a failed duplicate-upload cleanup affects quota only and recovery retries it. `src/files-api.js`: a status alone suffices when the error body is unparseable.
- `src/index.js` settings: static composition resolves before anything registers, so the invalid-snapshot branch only sees live settings failing a beyond-schema bound; it keeps serving the last good facts and logs once per bad snapshot. Every credential fact comes from the caller's snapshot (a rejected generation never leaks its key onto the previous endpoint); without the credentials seam the launch environment is the whole credential plane.
- `src/index.js` route registration binds effects to the apply fiber through the stable `ctx`. The registry captures the retry policy at registration, so a changed policy uses `registration.replace` (one synchronous registry section): dispose-and-re-register would publish an empty route set and observers would see the provider vanish and return.
- `src/serialize.js` (wire contract): text-less assistant turns send `""`, NEVER `null`. Pure tool-call turns replay `content` verbatim (`""`), and reasoning-only turns (a model answering wholly in the reasoning channel) are rejected by the live API with 400 "content or tool_calls must be set"; since the message is durable in the session log, one null bricks every later turn. `reasoning_content` is passed back on every reasoning-carrying turn (required on tool-call turns per the vendor thinking-mode guide; a gateway re-encoding for another vendor recovers the thinking signature by hashing that exact text). Harness tool results ride in user messages but DeepSeek needs `role: 'tool'`, and empty tool output still needs some content (`(no output)`).
- `src/translate.js`: reasoning deltas are handled before text (thinking mode interleaves them first) and an empty-string first chunk must not open a block; usage may ride the finish chunk or a trailing usage-only chunk (keep the latest); `parseSse` guarantees the `[DONE]` sentinel, so ending without it is a `STREAM_CLOSED` contract violation.
