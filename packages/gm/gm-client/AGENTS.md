# @freddie/freddie-gm-client

## Rationale

- `invariant.js` registers a no-op installer: gm-client is a spool dispatcher over `.gm/exec-spool/`, mounts `ctx.gm`, and owns no session events or durable logged relation to check; dispatch counters are process-local, not a reconstructable stream.
- `daemon.js` status and heartbeat reads treat `ENOENT` (not written yet) and `SyntaxError` (partial write) as absent; any other error throws. Liveness probe: `EPERM` means the pid exists but cannot be signaled (alive), `ESRCH` means gone, and Windows Node often omits `ESRCH` for a missing pid, so any other error on win32 means not alive.
- `spool.js` unlinks the response path before dispatch as defense in depth: `processEpoch` makes a collision implausible, but a leftover file (crash and restart within the same millisecond, failed cleanup) must never be mistaken for this dispatch's answer. If the fs watch fails (`EMFILE`, Windows), polling remains the waiter.
- Daemon: attach to the machine-wide native `agentplug-runner` (`~/.gm-tools/agentplug-runner spool`, fire-and-forget); the retired JS wrapper `plugkit-wasm-wrapper.js` never writes `.status.json`. Alive = fresh `ts` AND live pid (a killed daemon leaves a fresh-looking file). Hung = live pid with `ts` older than HUNG_MS and no future `busy_until`; queued `.inflight`/`.txt` in-files license waiting (a long codesearch drops `busy_until`). Boot polls readiness after spawn; concurrent boots per `cwd` share one promise (`inFlightBoots`), else each spawned its own runner.
- Machine heartbeat: `AGENTPLUG_HOME/daemon-status.json` else `~/.agentplug/daemon-status.json`, distinct from the per-project `.status.json`.
- Dispatch key is `<sessionId>-<processEpoch>-<N>`: the per-process counter restarts at 1, so a bare `sessionId-N` could read a stale out-file/`.ready` from an earlier run (live-verified). Plain-text-body verbs (exec_js stems, serp, browser, cdp) take `rawBody`, never JSON. One `sessionId` per `ctx.gm` instance; fanned-out subagents mint their own.
- `bert` verb body is `{verb: 'embed', text}` (`{op: ...}` silently returns the default capabilities response); model is BAAI/bge-small-en-v1.5, 384-dim, routed through the daemon. Per-call `cwd` (session workspace) beats config default `process.cwd()`. PRD/mutable `witness_text` maps to daemon `witness_evidence`.
