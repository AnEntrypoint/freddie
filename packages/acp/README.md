# acp/ — Agent Client Protocol automation

The ACP group exposes harness agents to programmatic clients over the Agent Client Protocol. It is an interoperability transport, not a presentation or human-interaction layer.

| Package | Role |
|---|---|
| [`acp/`](acp/README.md) | Automation-only ACP server. |

The server contract is documented in [`acp/README.md`](acp/README.md).
