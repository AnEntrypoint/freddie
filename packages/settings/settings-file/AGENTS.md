## Rationale

- `src/index.js` constructor: programmatic construction may bypass Schemastery normalization, so `resolveSpec(config)` resolves the same defaults in one explicit step either way.
- `src/index.js` `persist`: one document backs every namespace, so writes from different namespace queues serialize with each other and with watcher reloads on one operation chain; each render must see the text the previous operation committed or a sibling section silently vanishes from disk.
- `src/index.js` `persistSection`: the parent directory is created first (mode `0700`, the harness home holds user-private documents) because the writer lock's exclusive create needs it before `writeFileAtomic` could. Inside the lock, `reconcileFromDisk` folds in on-disk state this process has not seen (edit inside the watcher debounce, missed change, another process) so a render cannot resurrect a stale document; an unparsable on-disk document fails the write loudly instead of overwriting a manual edit. The file is written `0600` because it may hold personal values.
- `src/index.js` `queueRefresh` catch: only an invariant violation escaping the commit path can reject a refresh; it is logged so the operation queue survives and one poisoned commit cannot end hot reloading forever.
- `src/index.js` `[Service.init]`: a parse failure in the base init is a boot failure (an existing-but-invalid document must never be silently ignored or overwritten). One reconcile on watcher `ready` closes the gap where a change between the base load and watcher activation fires no event. Teardown sets `closed` and quiesces every operation chain even when no watcher is configured.
- `src/index.js` YAML parse: `prettyErrors` is on only for `linePos`; `error.message` is never used because the parser quotes the offending source line and a settings document can hold a `role('secret')` value.
- `src/index.js` mutable tree re-parse: `this.text` only caches content that already parsed, so the second `parseDocument` (for the comment-preserving tree) cannot fail and `parse()` already rejected non-map roots.
