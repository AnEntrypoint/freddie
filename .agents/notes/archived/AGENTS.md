# AGENTS.md — Archived Agent Notes

Archived Agent Notes under the class directories are frozen historical snapshots, not current authority. Never edit, reformat, repair, delete, or move a sealed file; use an active Agent Note or current documentation for new decisions and facts.

The archival change may only relocate the file, insert an `Archived: YYYY-MM-DD` line below `Status: implemented`, and repair or delete inbound links. Do not inspect, verify, or repair links out of archived notes.
